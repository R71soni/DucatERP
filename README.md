# DuctERP

DuctERP is a Java Full Stack ERP Web Application.

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- PostgreSQL
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Apache Tomcat

## Features
- Admin Login
- Student Management
- Trainer Management
- Course Management
- Attendance Management
- Fees Management
- Authentication
- Dashboard
- Session Management

## IDE
- Eclipse IDE

## Database
- PostgreSQL

## Server
- Apache Tomcat 11
